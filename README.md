# KMUTT MARKET – ตลาดนัดและร้านค้าภายในมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี (มจธ.)

> **"หิวเมื่อไหร่ คิดถึงตลาด มจธ."** — แพลตฟอร์มค้นหาร้านอาหาร เครื่องดื่ม คาเฟ่ประจำตึก โรงอาหาร S14 และตลาดนัดภายใน มจธ. บางมด

---

## 1. ภาพรวมระบบ (Project Overview)
- **สำหรับนักศึกษาและผู้เยี่ยมชม (Visitors / Students):** ค้นหาร้านน่ากินและเมนูเด็ดใน มจธ., ตัวช่วยสุ่มมื้ออาหาร **"วันนี้กินอะไรดีใน มจธ.?"**, ดูแผนที่พิกัดอาคารจริง (Leaflet + OpenStreetMap) คู่กับผังล็อกตลาดนัด S2, เช็กตารางร้านเปิดขายวันนี้ตามเวลา `Asia/Bangkok`, กดบันทึกร้านโปรดได้ทันทีโดยไม่ต้องบังคับล็อกอิน และเขียนรีวิวร้านค้า
- **สำหรับผู้ประกอบการร้านค้า (Vendors):** จัดการข้อมูลร้านค้าของตนเอง เพิ่ม/ลบ/แก้ไขเมนู ราคา สถานะพร้อมจำหน่าย และเวลาเปิด–ปิดร้าน (`/vendor/*`)
- **สำหรับผู้ดูแลระบบ (Administrators):** จัดการร้านค้าทั้งหมด เมนู หมวดหมู่ ตารางตลาดนัด ผังล็อกตลาดนัด ตรวจสอบรีวิว จัดการสิทธิ์ผู้ใช้ และตั้งค่าอัตราค่าบริหารพื้นที่ (`/admin/*`)

---

## 2. โครงสร้างฐานข้อมูลและการเชื่อมต่อ (Database & Dual-Mode Architecture)
1. **Supabase PostgreSQL Migrations:**
   - `supabase/migrations/001_initial_schema.sql`: ตารางครบทั้ง 12 ตาราง (`profiles`, `shops`, `categories`, `products`, `shop_schedules`, `market_events`, `market_stalls`, `favorites`, `reviews`, `announcements`, `shop_data_sources`, `activity_logs`) พร้อม Indexes และ RLS Policies
   - `supabase/migrations/002_seed_data.sql`: ข้อมูลตั้งต้นทางการจาก BPUU KMUTT
2. **Local Persistent Database Fallback:**
   - สามารถรันใช้งานและทดสอบระบบ CRUD ทุกหน้าได้ทันทีผ่าน `/api/market-data` และไฟล์ฐานข้อมูล `data/kmutt-market-db.json` โดยไม่ต้องรอตั้งค่าคีย์ภายนอก

## 3. วิธีรันโปรเจกต์ได้ทันที (Zero-Wait Instant Start)

```bash
# รันเซิร์ฟเวอร์ได้ทันทีด้วย Node.js (ไม่ต้องรอ npm install)
node server.mjs
# หรือ
npm run dev
```

เปิดเบราว์เซอร์ที่ **`http://localhost:3080`**
สามารถกดปุ่ม **"โหมดจำลองสิทธิ์"** ที่แถบด้านบนสุดเพื่อสลับทดสอบสิทธิ์ **ผู้เยี่ยมชม (Guest)**, **นักศึกษา (Student)**, **ร้านค้า (Vendor)** และ **ผู้ดูแลระบบ BPUU (Admin)** ได้ในคลิกเดียว
